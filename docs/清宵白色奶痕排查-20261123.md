# 清宵 060「胸前白色奶痕」排查记录

> 日期：2026-11-23
> 现象：清宵（邪·剑仙 序列060）胸口一直有白色奶痕状贴花；用户记得最早没有
> 结论：**不是文件损坏，是面板材质选项被持久化成了「带奶痕」那套（key_11=4）**

---

## 一、排查过程（走过的弯路）

| 步骤 | 假设 | 结果 |
|---|---|---|
| 1 | 双身形叠加（mod.ini + mod-thicc.ini 同 guid） | 部分成立，但不是奶痕原因 |
| 2 | 面板部件 16「乳贴」默认开 | 关掉后乳环消失，奶痕仍在 |
| 3 | 面板部件 23「骷髅抓手」默认开 | 关掉后骷髅手消失，奶痕仍在 |
| 4 | 部件 14「声痕」 | 关掉后仍在 |
| 5 | 完整版包损坏 | 外层 + 两个内层包 `unrar t` 全部通过，**文件完好** |
| 6 | 改 mod.ini / Out UI.ini 的默认值 | **改了没变化** ← 关键线索 |
| 7 | 检查 d3dx_user.ini | **发现面板状态存档 key_11 = 4** |

---

## 二、真正原因

```text
3dmigoto 会把面板里切过的选项写进 d3dx_user.ini
这个存档的优先级高于 mod.ini / Out UI.ini 里的默认值
所以改 ini 默认值看起来"完全没效果"

存档文件：
  %APPDATA%\XXMI Launcher\WWMI\d3dx_user.ini
对应行：
  $\mods\qingxiao-fallensword\buttonui\out ui.ini\key_11 = 4
```

`key_11` 是「身体材质」选择，对应贴图如下：

| key_11 | 使用的贴图 | 外观 |
|---|---|---|
| 0 | 4_3_0_0.dds | 干净 |
| 1 | 4_3_1_0.dds | 干净（作者默认） |
| 2 | 4_3_0_1 / 4_3_0_2 | 另一套皮肤质感 |
| 3 | 4_3_0_3 / 4_3_0_4 | 另一套 |
| **4** | **4_3_2_0 / 4_3_2_1** | **带白色奶痕（当时的状态）** |
| 5 | 4_3_2_2 / 4_3_2_3 | 带奶痕的另一种 |

另外 `key_36` 在每种模式下再二选一（贴图变体 A/B）。

---

## 三、修复

```text
修改 d3dx_user.ini 中 Qingxiao 面板的存档：
  key_11 = 4 → 1   身体材质换成干净版
  key_14 = 1 → 0   关声痕
  key_16 = 0       关乳贴（乳环）
  key_23 = 0       关骷髅抓手
  key_25 = 2 → 0   关心魔手

⚠ 必须在游戏完全退出后改：
  游戏退出时会把当前面板状态写回 d3dx_user.ini，运行中改会被覆盖
```

修改后进游戏，胸口恢复干净。

## 五、教训

1. **改 ini 不生效时，先查 `d3dx_user.ini` 的 persist 存档**，不要继续改文件。
2. 存档路径固定的：`%APPDATA%\XXMI Launcher\WWMI\d3dx_user.ini`。
3. 改存档必须在游戏完全退出后（进程 `Client-Win64-Shipping` 也要退），否则退出时会覆盖。
4. 「双身形 ini 同 guid」确实是隐患，但与奶痕无关，是两个独立问题。
5. 判断贴图问题最有效的方法：把 `Textures\*.dds` 转成 png 直接看内容，而不是猜。
