## 一、核对方法

```text
对 19 个爱发电完整版包逐一做三件事：
  1. unrar l 取“解压后总字节 / 文件数”（需各自密码）
  2. 只解 *.ini 取 object_guid
  3. 用 guid 找到 Mods 里当前生效目录，比较体积

判定：
  生效体积 ≈ 完整版体积        → ✅ 完整版
  生效体积 ≈ 免费版体积        → ❗ 装错了
  包里有包（嵌套 rar）        → 需再解一层，单独判断
```

## 三、修掉的具体问题

### 1. 菲比 041「混合残骸」（面板关不掉的直接原因）

```text
原状：mod-自动生成.ini 的 namespace 是 cx_Mod019
      但 ButtonUI\Out UI.ini 判断的是 cx_Mod041
      → 命名空间对不上，面板绘制条件失效

处理：用爱发电完整版原包（密码见本地存档，不公开）重新解压重装
      guid 196860 / namespace cx_Mod041 一致
      同时停用重复法杖 Skin_22461（guid 22461 重复）
```

### 2. 爱弥斯 029 / 064 抢 guid 343302

```text
原状：Skin_343302 同时含 mod-自动生成.ini(029) 和 mod.ini(064)
      → 同一 guid 注册两次

      064 保留生效
      029 完整版（239 MB）另存库：爱弥斯\031_...-029-FULL
```

## 六、恢复方法

```text
想换回某个互斥皮肤：
  1. 停用当前生效的（文件夹名前加 DISABLED）
  2. 启用目标（去掉 DISABLED 前缀）
  3. 回游戏按 F10（保险起见重开游戏）

完整版重装：
  包在 F:\GameMods\WWMI-Mods\Downloads\_晨星_full\
  密码见本地《晨星完整版-密码与链接存档.csv》（不随仓库分发）
  解压后确认 ini 在第一层（套娃包要再解一层）
```

## 七、本次教训

1. **改键一定要逐套验证**：一次性批量改 79 个 ini 导致面板全炸、0 键失效，回滚花了很久。
2. **命名空间必须和 UI 引用一致**：041 那份残骸就是 namespace cx_Mod019 ↔ UI cx_Mod041。
3. **同 guid 只能一个生效**：多份注册会“看起来正常、偶发错乱”，很难查。
4. **体积相近 ≠ 版本相同**：晨星好几套免费版与完整版差异 < 1%，判定要靠包内 ini/guid，不能只看大小。
5. **persist 变量会跨启动**：`d3dx_user.ini` 里的持久值会盖过 ini 默认值，改默认值后要清理存档。
