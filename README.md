# 鸣潮 Mod 管理器（WuWa Mod Manager）

一套用于管理《鸣潮》外观 Mod 的 Windows 工具：**皮肤库扫描、双形态安装、按键编辑与冲突检测、反虚化开关**。

> ⚠️ **本仓库只包含工具代码，不包含任何 Mod 文件、模型、贴图或整合包**。
> Mod 的版权归各自作者所有，请自行获取并遵守作者的授权条款。

---

## 功能

### 🖥️ 桌面管理器（WPF）

参考 Vortex / Mod Organizer 2 的三栏布局。

- **左栏**：角色列表、刷新索引、导入外部 Mod、**反虚化开关**
- **中间**：搜索 + 卡片网格（缩略图 / 编号 / `双形态` 角标）
- **右栏**：大图预览、形态标签、可调档位、作者说明、**按键编辑区**

### 🎛️ 反虚化（角色贴近镜头不再变半透明）

> ⚠️ 先说结论：**反虚化和 Mod 目前互斥**，只能按模式分工。实测过程见
> [docs/反虚化与模式切换.md](docs/反虚化与模式切换.md)。

| 模式 | 反虚化 | 说明 |
|---|---|---|
| **光追模式** | ✅ 有效 | WuwaTFR（ReShade 插件）的 `EnableTFR=1` |
| **Mod 模式** | ❌ 无效 | RabbitFX 会先改写着色器，WuwaTFR 结构匹配不上 |

补充：早前网上流传的"RabbitFX `$censor` 是反虚化开关"是**误传**——它做的是解绑贴图
（`ps-t50/t51 = null`），实测对"镜头贴近变透明"无效，还会让依赖这些贴图的 Mod 丢贴图。

游戏内按键已移除（不再占用 `\`），改为**局外开关**：

- 双击桌面「反虚化 - 切换」→ 弹菜单（开 / 关 / 看状态 / 回车切换）
- 或管理器左上角拨动开关
- 状态存在 `.state/反虚化.json`，**启动器每次启动前自动同步**进 `WuwaTFR.ini`，
  所以不用记上次切了什么

### ⌨️ 按键管理

- **自动识别**：从每个 `mod.ini` 的 `[KeyXXX]` 段解析出功能名与当前键，**不依赖作者是否写了 readme**
- **冲突检测**：同一 ini 内两个功能用同一个键 → 标红提示
- **自动修复**：按 `0-9 → F1-F12 → 方向键 → Alt+数字` 的顺序推荐未占用键

### 🔀 双形态支持

卡提希娅 / 芙露德莉斯是两个不同的 `object_guid`，可以**各装一套互不覆盖**：

- 皮肤本身覆盖双形态 → 一键全装
- 只覆盖单形态 → 分别装到对应形态，或与另一套组合

### 🔁 模式切换与联动

启动器双击卡片即可切换 Mod / 光追 / 干净模式，切换过程会自动：

1. 等待游戏进程真正退出（最多 90 秒）
2. 等设置数据库刷盘稳定（避免写入被游戏退出流程覆盖）
3. 写三处光追开关并回读校验（DB / GameUserSettings / Engine.ini）
4. 同步反虚化状态到 `WuwaTFR.ini`
5. 直接拉起游戏（光追模式跳过官方启动器，预写设置才会生效）

### 🧰 配套脚本

| 脚本 | 作用 |
|---|---|
| `Mod管理器.ps1` | 桌面管理器（主入口） |
| `鸣潮启动器.ps1` | Mod / 光追 / 干净 三模式启动 |
| `反虚化开关.ps1` | 命令行/快捷方式切换反虚化 |
| `切皮肤.ps1` | 纯命令行换皮肤 |
| `解压皮肤.ps1` | 从整合包里批量解出皮肤到皮肤库 |
| `carve-整合包.ps1` | 从打包文件里提取 Mod 名单（只读） |
| `抽预览与说明.ps1` | 批量抽取预览图与作者说明 |
| `skin_server.py` | 网页版管理器（可选，本地 8791 端口） |

## 快速开始

### 1. 准备

- Windows 10/11
- PowerShell 5.1（系统自带）
- 已安装 XXMI Launcher + WWMI（Mod 加载器）
- 已有的 Mod 放在 `%APPDATA%\XXMI Launcher\WWMI\Mods\<名字>\mod.ini`

### 2. 配置

```powershell
# 在仓库根目录运行一次，会自动生成 config.json
powershell -NoProfile -ExecutionPolicy Bypass -File .\src\Mod管理器.ps1
```

然后编辑 `config.json`（或用 `config.example.json` 复制改名）：

```json
{
  "gameBin":  "D:/Wuthering Waves/Wuthering Waves Game/Client/Binaries/Win64",
  "modsDir":  "%APPDATA%/XXMI Launcher/WWMI/Mods",
  "skinsDir": "%USERPROFILE%/Documents/WuwaMods/Skins",
  "switchScript": "",
  "recordsDir": ""
}
```

支持 `%ENV%` 环境变量展开。

### 3. 建立皮肤库

把皮肤按下面的结构放进去（`编号_名字` 会被管理器识别为顺序号）：

```
Skins/
  卡提希娅/
    001_Woju Eleganta/
    002_Ecchi Valkyrie/
  ...
```

也可以直接在管理器左栏**粘贴任意文件夹绝对路径**导入，会自动分配下一个编号。

### 4. 使用

```text
双击 src\Mod管理器.ps1
→ 左栏选角色 → 中间点卡片 → 右侧看预览/按键 → 点「装到 XXX」
→ 回游戏按 F10 重载
```

> 首次安装某角色前，会自动把原有 Mod 备份到 `Skins\_原版备份\`，「恢复原版」按钮可一键还原。

## 配置文件说明

| 键 | 说明 |
|---|---|
| `gameBin` | 游戏 `.../Client/Binaries/Win64` 目录（内含 `dxgi.dll`、`WuwaTFR.ini`） |
| `modsDir` | XXMI 的 Mods 目录 |
| `skinsDir` | 皮肤库根目录（本工具管理） |
| `packDir` | 整合包解压出的角色目录（仅解压脚本用，可留空） |
| `switchScript` | 模式切换脚本路径（启动器用，留空则隐藏对应按钮） |
| `recordsDir` | 记录目录（启动器「打开记录目录」用） |

## 常见问题

**Q：换完皮肤游戏里没变化？**
先按 F10；如果无效，检查 `Mods\<角色>\mod.ini` 是否在**第一层**（本工具会自动拍平，手动放置时注意）。

**Q：开了光追 Mod 全部失效？**
`wwmi-dx12` 检测到光追会主动禁用全部 Mod，这是加载器行为，不是本工具的问题。光追模式下如需去虚化，用 WuwaTFR（ReShade 插件）。

**Q：按键改了没反应？**
改键写的是**皮肤库**里的 ini，需要点一次「装到…」把它同步到 `Mods`，再按 F10。

**Q：`\` 键以前能切反虚化，现在不行？**
已改为局外开关（管理器左上角 / 桌面「反虚化 - 切换」），不再占用游戏内按键。

**Q：切了模式进游戏发现光追没变？**
光追由三处共同决定：`LocalStorage.db` 的 `RayTracing`、`GameUserSettings.ini` 的
`sg.RayTracingQuality`、以及 **`Engine.ini` 的 `r.RayTracing.LoadConfig`**。
只写前两处的话，引擎初始化读不到，必须再重启一次才生效。
本仓库的切换脚本会把三处一起写并回读校验——如果你的脚本是旧版，请更新。

**Q：点启动器提示"检测到游戏仍在退出中"？**
正常。点 X 关游戏后进程往往还要几十秒才真正退出，启动器会等你，不用管。
超过 90 秒才会问你要不要强制结束。

**Q：卡片点一下没反应？**
卡片是**双击**启动。单击只会在状态栏提示"已选中 [X 模式]，再点一次即启动"。

**Q：为什么反虚化在 Mod 模式下无效？**
RabbitFX 与 WuwaTFR 抢同一批像素着色器，前者先改写，后者就匹配不上。
硬要用"按 hash 覆盖"的去透明 Mod（如 Prevent Transparency）就要放弃 RabbitFX，
而多数 Mod 的贴图依赖 RabbitFX。详见 [docs/反虚化与模式切换.md](docs/反虚化与模式切换.md)。
